# CampusConnect - Member 4 module

Copy the `lib/` folder from this download into your Flutter project (replace the
default `lib/main.dart`). Then follow the setup steps in the chat
(packages, `flutterfire configure`, Firestore + Storage rules).

Packages to install (run in the project root):

    flutter pub add firebase_core firebase_auth cloud_firestore firebase_storage image_picker url_launcher intl

Generated by `flutterfire configure` (do not write it yourself): `lib/firebase_options.dart`

A ready-made `pubspec.yaml`, `firestore.rules` and `storage.rules` are included.
